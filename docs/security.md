# Security and privacy

- API keys are read from provider SDK environment variables and must never be committed.
- Agent debug traces can contain scenario secrets and private character knowledge.
- Normal CLI output omits hidden facts and private thoughts.
- SQLite campaign files may contain unpublished story material.
- Do not expose future HTTP adapters directly to the public internet without authentication and transport security.
- A cloud-agent configuration sends the projected prompt content to the configured provider. Review provider data-handling terms before using private material.
