### 3.2 `tests/test_story_reliability.py` — 15 个用例全部通过，未暴露新 bug

钉住的合同（此前全部只隐含存在）：

| 组 | 合同 |
| --- | --- |
| schema | 未知版本拒载；缺省按 v1；`write_bundle` round-trip 带版本 |
| 事务 | 未 commit 零痕迹；`abort()` 只落 `story_turn_aborted` 审计（含缓冲事件类型）；弃 tx + 重开 store（模拟进程崩溃）→ 恢复最后 committed 快照；绕过 runtime 的重复 request_id commit → `ValueError` 且不留半个回合 |
| request-id | **全局 PRIMARY KEY**（非 session/branch 局部）：同 id 不同 payload 静默重放首个结果（dedup-key 语义）；跨分支/跨会话复用 → runtime 抛 `RuleViolation` |
| 分支 | 子分支祖先事件投影冻结在 `forked_from_turn`，父分支后续回合对子不可见 |
| compiler 自愈粒度 | 坏章节卡 → 仅该章重生成（1 调用）；卡内 `source_sha256` 不符 → 重生成；坏 `source_plan.json` → 仅 plan 重算；坏 `arcs_state.json` → 仅弧阶段重跑；**坏 `manifest.json` → 各 artifact 按 SHA/digest 自校验整体续跑，0 调用** |

## 4. 架构红线 | Non-negotiable constraints（不变）

1. **Runtime authority**：模型只返回 typed proposal 或 prose；状态、骰点、权限、分支、提交由确定性 runtime 拥有。
2. **Context isolation**：`CampaignState`、`StorySessionState`、`StoryBundle` 不互转，不做跨领域 God object。
3. **Shared kernel stays small**：共享层只放 SQLite 生命周期与 LLM transport。
4. **Append-only history** + **Atomic commit**。
5. **Adapters stay thin**。
6. **Evidence boundary**：编译产物必须保留 source refs，模型推断不能绕过 Bundle 校验成为 canon。
