## 3. 架构红线 | Non-negotiable constraints

1. **Runtime authority**：模型只返回 typed proposal 或 prose；状态、骰点、权限、分支、提交由确定性 runtime 拥有。
2. **Context isolation**：`CampaignState`、`StorySessionState`、`StoryBundle` 不互转，不做跨领域 God object。
3. **Shared kernel stays small**：共享层只放 SQLite 生命周期与 LLM endpoint/config/JSON transport 等无语义能力。
4. **Append-only history** + **Atomic commit**：一个回合的事件、快照、幂等结果必须原子提交，失败不留半个权威回合。
5. **Adapters stay thin**：CLI/Web 不直接操作 SQL，不让 HTTP schema 反向成为 domain schema。
6. **Evidence boundary**：编译产物必须保留 source refs，模型推断不能绕过 Bundle 校验成为 canon。

1. **Web 控制台没有 Story Mode 界面**：`/api/story/...` 已存在且有测试，但 `web/static` 只有 Campaign 页面（library/compose/campaigns/settings）。文档已改为“该 surface 面向程序客户端”，M3 拆完路由后再补页面。

3. **无 CI**：`.github/workflows` 不存在，四件套全靠本地手动。
4. **`/api/settings` 的 `key_status` 把 provider 硬编码成 `deepseek`**：属基线遗留（早于本轮），且该端点可写 `config/agents.yaml`；公开暴露前需要认证/限流（`docs/security.md` 已声明边界，但实现未跟上）。
